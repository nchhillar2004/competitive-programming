## Find the Most Frequent Character in a String

### Problem Statement

Given a string, find the character that appears the maximum number of times in the string.  
Also print the number of times that character occurs.

Ignore spaces while counting characters.

### Input
A single string.

### Output
Print the character with the highest occurrence and its count.

### Example

**Input:**
```
abbcccdddd
```

**Output:**
```
d repeats 4 times.
```
